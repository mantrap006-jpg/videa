# Videa

Next.js + MongoDB MVP for a watch-and-reward video platform.

## Setup

1. Run npm install.
2. Copy .env.example to .env.local.
3. Set MONGODB_URI, JWT_SECRET, and ADMIN_KEY.
4. Run npm run dev.

The application rewards users with points controlled by Videa; these are not YouTube payments. Add server-side watch verification, anti-fraud controls, payout verification, terms and privacy controls before real-money launch.
